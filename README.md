# Lecture OCR для macOS

Нативное приложение SwiftUI для пакетного распознавания лекций. Изображения обрабатываются локально, а результат можно просматривать по блокам, исправлять и экспортировать в DOCX, TXT или Markdown.

## Возможности

- Перетаскивание и выбор JPG/JPEG, PNG, HEIC/HEIF и PDF. PDF разворачивается на отдельные страницы; очередь можно переставлять и очищать.
- Три переключаемых режима: PaddleOCR-VL 1.6 для разбора страницы целиком, PP-StructureV3 для структуры и классического OCR, «Гибрид» для PP-StructureV3 с дополнительной проверкой подозрительных строк моделью PP-OCRv6 Cyrillic ONNX.
- Русский текст по умолчанию, постраничный прогресс, редактирование распознанных блоков и подсветка соответствующего места на снимке при наведении.
- Экспорт форматированных блоков в DOCX и Markdown, обычного текста в TXT.
- Автоматическая мягкая коррекция освещения/контраста (CLAHE), классификация ориентации страницы и выправление деформации листа. Исходный файл не изменяется.
- Масштабирование снимка кнопками и жестом сведения/разведения пальцев на трекпаде; кнопка «Вписать» возвращает страницу целиком.
- История распознанных страниц с локально сохранёнными оригиналами, улучшенными превью и исправленным текстом. Галочка в очереди отмечает уже распознанную страницу.
- Настройки хранения и лимита истории, расположения библиотеки и каталога моделей, режима запуска и анимаций. Историю можно объединить из ZIP-копии; настройки переносятся JSON-файлом.
- Текстовая панель показывает только выбранную страницу. Наведение на блок выделяет его область на соответствующем снимке.

## Совместимость и ограничения

- Сборка рассчитана на Mac с Apple Silicon (`arm64`) и macOS 15 Sequoia или новее. Она использует CPU PaddlePaddle. GPU, Metal и MPS не заявляются.
- PaddleOCR публикует отдельное руководство для Apple Silicon; в нём указано, что точность и скорость проверялись на M4, а совместимость с другими чипами Apple официально ещё не подтверждена. Поэтому режим VL на M1 включён как локальная CPU-конфигурация, но требует проверки на конкретном Mac и может быть медленным.
- PP-OCRv6 Cyrillic в гибридном режиме является второй гипотезой распознавания, а не гарантированным распознавателем скорописи. Если два варианта расходятся, эвристика может выбрать неверный. Низкая разборчивость, курсив и наклонные рукописные записи требуют ручной правки.
- Форматирование восстанавливается по распознанным блокам и геометрии страницы. Оно не копирует исходную типографику один в один; при сложной вёрстке, таблицах и схемах экспорт нужно проверить.
- Приложение собирается без Developer ID подписи и notarization. macOS может потребовать один раз открыть его через Finder → правый щелчок → «Открыть».

## Модели

Веса моделей не встраиваются в `.app` и во время распознавания автоматически не скачиваются. По умолчанию приложение ищет модели здесь:

```text
~/Library/Application Support/Lecture OCR/PaddleX/official_models/
```

В настройках можно выбрать другой каталог, в том числе на внешнем диске. Выберите папку `official_models` или родительскую папку PaddleX, внутри которой находится `official_models`. В выбранной папке должны быть подпапки с именами моделей из списка ниже.

Общие модели:

- `PP-DocLayoutV3`
- `PP-LCNet_x1_0_doc_ori`
- `UVDoc`

Для режима **PP-StructureV3** дополнительно нужны `PP-OCRv5_mobile_det` и `eslav_PP-OCRv5_mobile_rec`. Для **Гибрида** добавьте `PP-OCRv6_medium_rec_cyrillic_onnx`. Режим **PaddleOCR-VL 1.6** использует папку `PaddleOCR-VL-1.6`.

Внутри папок модели должны находиться файлы из полного снимка модели: например `inference.yml` и веса Paddle, `model.safetensors` для VL либо `inference.onnx` для ONNX-модели. Приложение сообщает, если папки нужной модели нет; эта проверка существования папки ещё не гарантирует целостность всех её файлов.

## Где хранится библиотека

По умолчанию приложение сохраняет историю в:

```text
~/Library/Application Support/Lecture OCR/Library/
```

Внутри находятся `Originals/` (копии исходных файлов), `Previews/` (страницы после подготовки), `manifest.json` (тексты и порядок страниц) и `queue.json` (состояние очереди). Библиотеку можно перенести в настройках; при переносе файлы копируются, старую папку приложение не удаляет. Отключение истории влияет только на новые изображения. Для защиты места можно ограничить историю количеством страниц; уменьшение лимита удаляет самые старые записи и их локальные копии.

ZIP-резервная копия содержит библиотеку истории и экспорт настроек `settings.json`. Импорт ZIP объединяет записи с текущей историей и применяет параметры истории и интерфейса, сохраняя пути к папкам на текущем Mac. Отдельный JSON экспортирует все настройки, включая пути; он не включает изображения и распознанные страницы. После переноса настроек на другой Mac пути к моделям и библиотеке при необходимости выбери заново.

## Сборка и первый запуск

Нужен Mac Apple Silicon, Xcode Command Line Tools, `uv` и интернет для установки самого Python-окружения и библиотек приложения. Это не загружает веса OCR-моделей.

```sh
xcode-select --install
brew install uv
cd /путь/к/папке-проекта
./build-app.sh
```

Скрипт соберёт автономное приложение в:

```text
build/Lecture OCR.app
```

Перетащите его в `/Applications`, затем откройте. После установки Terminal для обычной работы не нужен. Модели должны быть заранее помещены в каталог из раздела выше.

## Работа с приложением

1. Добавьте фотографии или PDF кнопкой «Добавить» либо перетащите их в окно.
2. Проверьте очередь и порядок страниц.
3. Выберите один из трёх режимов и нажмите «Распознать».
4. Снимок можно приблизить/отдалить кнопками или жестом трекпада; «Вписать» показывает страницу целиком.
5. Наведите курсор на блок текста, чтобы подсветить его область на снимке. Двойной щелчок по блоку включает исправление; исправления сохраняются в историю, если она включена.
6. Переключитесь с «Очередь» на «История», чтобы открыть страницу после перезапуска приложения. В истории её можно вернуть в очередь.
7. В меню «Экспорт…» выберите DOCX, TXT или Markdown. Для параметров хранения и переноса используйте шестерёнку «Настройки».

## Состав проекта

- `LectureOCR/App.swift` — интерфейс, очередь, история, настройки, PDF/HEIC, просмотр с масштабированием и экспорт.
- `LectureOCR/LibraryStore.swift` — локальные пути библиотеки, manifest/session и чтение/запись.
- `LectureOCR/worker.py` — локальный worker для PaddleOCR и предобработка изображений.
- `LectureOCR/export_docx.py` — оформление DOCX.
- `LectureOCR/make_icon.swift` — генерация иконки приложения (концепция 1: документ и рамка сканирования).
- `DESIGN.md` — принципы интерфейса, анимации и доступности.
- `LectureOCR/requirements.txt` — зависимости встроенного Python.
- `build-app.sh` — сборка автономного `.app`.

## Что проверять на конкретном Mac

Сборка `.app` и импорт PaddleOCR проверяются отдельно от запуска моделей. Успешная компиляция не доказывает, что каждый комплект весов цел, что все режимы запустятся на конкретном Mac или что OCR выдаст корректный текст. Скорость и качество режима VL на M1 заранее не обещаются.
